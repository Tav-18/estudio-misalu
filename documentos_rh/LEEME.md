# Documentos de Recursos Humanos

Todo lo que está aquí aparece solo en **Área interna → Recursos Humanos**
(cuentas de RH y Administración). La página lo lista sola: no hace falta tocar código.

```text
documentos_rh/
├── expedientes/
│   └── Nombre del candidato/
│       ├── 1 Documentos de ingreso/    Solicitud de empleo, Currículum vitae
│       ├── 2 Pruebas psicométricas/    Cleaver, Zavic, Terman, Moss, Beta IV, FIGS, hoja de calificación
│       ├── 3 Pruebas proyectivas/      Machover, Persona bajo la lluvia
│       └── 4 Reportes/                 Reporte mixto
└── manual/
    └── Manual de políticas ... .pdf
```

## Reglas para agregar documentos

- **Nombre del archivo:** `Título - Candidato.pdf` (p. ej. `Cleaver - Dylan.pdf`). En la página se
  muestra solo el título ("Cleaver").
- **PDF + original:** si junto al PDF hay un Word/Excel con el **mismo nombre**, se muestra como un
  solo documento con botón para descargar el original.
- **Carpetas:** el número inicial solo define el orden y no se muestra. Una carpeta nueva aparece
  como otra categoría.
- Para que se vean en el navegador, sube los documentos en **PDF** (Word: Archivo → Guardar como → PDF).
